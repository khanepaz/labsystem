# کتابخانه اختیاری Excel

برای فعال شدن پشتیبانی مستقیم از فایل‌های `.xlsx`:

1. فایل `xlsx.full.min.js` را از آدرس زیر دانلود کنید:
   https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js

2. آن را با همین نام داخل همین پوشه `lib/` قرار دهید.

3. صفحه را رفرش کنید.

اگر این فایل وجود نداشته باشد، سیستم فقط از CSV پشتیبانی می‌کند (که کاملاً کار می‌کند).
