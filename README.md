# Laboratory System (سیستم مدیریت آزمایشگاه)

نرم‌افزار مدیریت مدارک، نسخه‌ها، درخواست‌های تغییر، گردش کار تأیید مدیر کیفیت و سوابق آزمایشگاه.

|------|--------|

### قابلیت‌های باقی‌مانده / محدود

- خروجی Excel پیشرفته گزارش‌ها
- اسکن واقعی پوشه سوابق (در حال حاضر دستی)
- پشتیبانی مستقیم فایل‌های `.xlsx` (فعلاً CSV قوی پشتیبانی می‌شود)
- قفل‌گذاری قوی چندکاربره (محدودیت معماری فایل‌محور)

## معماری

**Pure Client-Side (HTML + CSS + JavaScript)**

- بدون سرور، بدون پایتون، بدون نصب پکیج
- ذخیره‌سازی JSON
- File System Access API (Edge / Chrome)
- تمام وابستگی‌ها محلی

## نحوه اجرا

1. پروژه را از گیت‌هاب دانلود یا کلون کنید.
2. فایل `run.bat` را اجرا کنید (یا `index.html` را در Edge/Chrome باز کنید).
3. پوشه داده‌ها را انتخاب کنید.
4. در اولین اجرا مراحل راه‌اندازی را طی کنید.

### نکات مهم

- برای ورود مدارک: فایل Excel را به **CSV UTF-8** ذخیره کنید.
- در Share شبکه ممکن است محدودیت مرورگر وجود داشته باشد.
- امنیت واقعی به مجوزهای پوشه در ویندوز وابسته است.

## نقش‌ها و اصل حاکم

- **مدیر سیستم**: اعمال نهایی تغییرات + مدیریت کاربران + ورود Excel
- **مدیر کیفیت**: تأیید / رد درخواست‌ها
- **مدیر فنی**: ثبت درخواست اصلاح
- **مشاهده‌کننده**: فقط مشاهده

**اصل حاکم:** فقط مدیر سیستم پس از تأیید مدیر کیفیت می‌تواند نسخه جاری مدرک کنترل‌شده را تغییر دهد.
