# Laboratory System (سیستم مدیریت آزمایشگاه)

نرم‌افزار مدیریت مدارک، نسخه‌ها، درخواست‌های تغییر، گردش کار تأیید مدیر کیفیت و سوابق آزمایشگاه.

## وضعیت فعلی پیاده‌سازی (اکتبر ۲۰۲۶)

### قابلیت‌های تکمیل‌شده

| بخش | وضعیت |
|------|--------|
| راه‌اندازی اولیه (انتخاب پوشه + سازمان + مدیر اصلی) | ✅ |
| احراز هویت و نقش‌ها | ✅ |
| مدیریت کاربران (ایجاد، فعال/غیرفعال، تغییر رمز) | ✅ |
| مدیریت مدارک (فهرست، جزئیات، نسخه‌ها) | ✅ |
| هشدار مدرک منسوخ | ✅ |
| گردش کار درخواست تغییر | ✅ |
| تأیید/رد توسط مدیر کیفیت | ✅ |
| اعمال نهایی فقط توسط مدیر سیستم | ✅ |
| جلوگیری از تأیید درخواست خود | ✅ |
| ورود اطلاعات از CSV/Excel با نگاشت ستون | ✅ |
| داشبورد و نشان تعداد درخواست‌ها | ✅ |
| پشتیبان‌گیری خودکار هنگام ذخیره | ✅ |
| رابط کاملاً فارسی و RTL | ✅ |

### قابلیت‌های باقی‌مانده

- مدیریت سوابق (درخت پوشه‌ها)
- مدیریت استانداردها و بندها
- گزارش‌های پیشرفته و خروجی Excel
- پشتیبان‌گیری/بازیابی دستی پیشرفته
- بهبود پشتیبانی از فایل xlsx واقعی (در حال حاضر CSV قوی پشتیبانی می‌شود)

## معماری

**Pure Client-Side (HTML + CSS + JavaScript)**

- بدون نیاز به سرور، پایتون یا نصب پکیج
- ذخیره‌سازی در فایل‌های JSON
- استفاده از File System Access API (Edge / Chrome)
- تمام وابستگی‌ها محلی

## نحوه اجرا

1. کل پروژه را دانلود کنید.
2. فایل `run.bat` را اجرا کنید (یا `index.html` را مستقیماً در Edge/Chrome باز کنید).
3. پوشه داده‌ها را انتخاب کنید.
4. اگر اولین بار است، مراحل راه‌اندازی را طی کنید.

### نکات مهم

- برای ورود مدارک از Excel: فایل را به صورت **CSV UTF-8** ذخیره کنید و از منوی «ورود Excel» استفاده کنید.
- در محیط Share شبکه ممکن است محدودیت‌هایی وجود داشته باشد.
- کنترل دسترسی واقعی به مجوزهای پوشه در ویندوز وابسته است.

## نقش‌ها

- **مدیر سیستم**: اعمال نهایی تغییرات + مدیریت کاربران + ورود Excel
- **مدیر کیفیت**: تأیید / رد درخواست‌های تغییر
- **مدیر فنی**: ثبت درخواست اصلاح
- **مشاهده‌کننده**: فقط مشاهده

**اصل حاکم:** فقط مدیر سیستم پس از تأیید مدیر کیفیت می‌تواند نسخه جاری مدرک را تغییر دهد.
