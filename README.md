# Laboratory System (سیستم مدیریت آزمایشگاه)

نرم‌افزار مدیریت مدارک، نسخه‌ها، درخواست‌های تغییر، گردش کار تأیید مدیر کیفیت و سوابق آزمایشگاه مطابق با الزامات واقعی آزمایشگاه صنعتی و استانداردهایی مانند ISO/IEC 17025.

## معماری نهایی

**Pure Client-Side Web Application**

- HTML + CSS + JavaScript خالص
- بدون نیاز به سرور، پایتون، Node.js یا هیچ وابستگی خارجی در زمان اجرا
- تمام کتابخانه‌ها (از جمله خواندن Excel) به‌صورت محلی همراه پروژه هستند
- ذخیره‌سازی داده‌ها در فایل‌های JSON
- رابط کاربری کاملاً فارسی و راست‌چین (RTL)

### چرا این معماری؟

به دلیل محدودیت‌های محیط هدف (پایتون ۳.۵.۱ و عدم امکان نصب پکیج، محدودیت File System Access API روی Share ویندوز)، معماری سرورمحور کنار گذاشته شد.

### نحوه اجرا

1. کل پوشه پروژه را دانلود یا کلون کنید.
2. فایل `run.bat` را اجرا کنید (یا مستقیماً `index.html` را با مرورگر Edge یا Chrome باز کنید).
3. در اولین اجرا، پوشه داده‌ها را انتخاب کنید و مراحل راه‌اندازی را طی کنید.

### ساختار پوشه‌ها

```
labsystem/
├── index.html              # نقطه ورود اصلی
├── run.bat                 # راه‌انداز سریع در ویندوز

├── css/
│   └── style.css

│   ├── auth.js             # احراز هویت و نقش‌ها

```

### محدودیت‌های مهم (شفاف)

- نوشتن هم‌زمان چند کاربر روی یک فایل JSON ممکن است باعث تداخل شود. مکانیزم تشخیص تعارض بر اساس timestamp پیاده‌سازی شده است.
- File System Access API روی بعضی مسیرهای شبکه ویندوز کامل کار نمی‌کند. در این حالت از روش دستی (دانلود/آپلود JSON) استفاده کنید.
- کنترل دسترسی برنامه در سطح رابط کاربری و منطق است. اگر کاربر به پوشه داده‌ها دسترسی مستقیم فایل‌سیستمی داشته باشد، می‌تواند فایل‌ها را دستی ویرایش کند.
- تاریخچه و داده‌ها غیرقابل‌دستکاری کامل نیستند (چون فایل‌محور هستند).

### نقش‌ها

- **مدیر سیستم**: اعمال نهایی تغییرات پس از تأیید مدیر کیفیت
- **مدیر کیفیت**: تأیید / رد درخواست‌های تغییر
- **مدیر فنی**: ثبت درخواست اصلاح
- **مشاهده‌کننده**: فقط مشاهده

اصل حاکم: **هیچ نقشی به‌جز مدیر سیستم تعیین‌شده نمی‌تواند نسخه جاری مدرک کنترل‌شده را مستقیماً تغییر دهد.**
